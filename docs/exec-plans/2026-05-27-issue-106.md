# Issue #106: [design] TokenBar 토큰 초과 시 오버플로우 UI 추가

> Labels: design, frontend | Milestone: 없음

## 목표

챌린지 보상으로 `remaining > max`가 될 경우, 초과분을 골드 색상으로 바에 이어서 렌더링한다.
초과 상태일 때 숫자도 골드 텍스트로 강조한다.

## 관련 파일

- `components/TokenBar.tsx` — 메인 수정 대상

## 작업 분해

- [ ] `remaining > max` 여부 감지 로직 추가
- [ ] 기본 구간(0~max): 기존 green/amber/red 색상 유지, 100% 기준
- [ ] 초과 구간: 전체 바에서 초과분 비율 계산 (상한선 `max * 1.5` 기준)
- [ ] 초과 구간 div를 골드(`bg-yellow-400`) 색상으로 렌더링
- [ ] 초과 상태일 때 remaining 숫자 텍스트를 `text-yellow-500 font-bold`로 강조

## 완료 기준

- `remaining <= max`: 기존 동작 완전히 동일
- `remaining > max`: 바가 100% 채워진 뒤 초과분이 골드색으로 이어서 표시
- 초과 구간 텍스트 강조 표시
- Tailwind 클래스만 사용 (inline style 최소화)
